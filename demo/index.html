webserv demo

webserv

A non-blocking, epoll-based HTTP/1.1 server written in C++98. This site lets you try the server's features one by one from the browser.

Pages

  • Request inspector — the incoming request and the environment variables passed to CGI
  • Calculator — GET query string, the same calculation in Python and PHP (multiple CGI)
  • Online C/C++ compiler — POST body to CGI, compile and run with gcc/g++
  • Cookies and sessions — required/optional cookies, Set-Cookie, session
  • Status codes — 201, 301, 403, 404, 405, 413, 502, 504...
  • Second site (port 4243) — different port, different content
